# Carmonela Studio
Instrument gratuit de planificare a promovării organice pentru [@carmonela](https://www.tiktok.com/@carmonela).

## Interfață web
Deschide `index.html` în browser. Funcționează pe telefon și desktop, fără server și fără cont. Pentru publicare gratuită: Settings → Pages → Deploy from a branch → main → / (root).

Funcții: idee zilnică, texte de distribuire cu copiere, înregistrarea manuală a urmăritorilor, calculul diferenței și export CSV. Progresul este stocat doar în browserul curent; ștergerea datelor browserului îl poate elimina.

## Program Python existent
```bash
python promovare_carmonela.py plan
python promovare_carmonela.py record 850
python promovare_carmonela.py stats
```

## Limite
Nu poate obține automat urmăritori doar dintr-un link. Nu se autentifică în TikTok, nu cumpără urmăritori, nu trimite mesaje în masă și nu publică automat. Promovarea efectivă necesită conținut și distribuire voluntară.
